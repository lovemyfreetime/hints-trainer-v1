Try your first hint

  1. Open HINTS at the top right.
  2. Select Load practice layout, then Find a shot.
  3. Move through the five hint levels to reveal the position guide, aim, speed, and explanation.
  4. Choose Set up this shot, close the HINTS panel, then select Execute Shot.

Undo Last Shot restores the previous layout or shot setup.

This preview covers direct shots in normal 8-ball and 9-ball play. Banks, kicks, breaks, and touching-ball situations are not coached yet.

The shaded position areas are sampled guides, not guaranteed safe zones. This is a test version.

On a computer, extract the entire ZIP before opening this page. Keep the files together. The browser package works locally without a native installer. Mobile browsers may require the files to be hosted; this download is not an Android installation package.

Photo analysis and native installers are not included in this small coaching preview.
